# Q8_0 与 vLLM 在相同显存预算下的全量对照

Q8_0 / llama.cpp 实测整卡峰值 6,695 MiB，按该值反馈校准三个 vLLM 版本；每组 8,096 条、八语各 1,012 条、128 并发。
COMET 与 MetricX 对本轮 18,353 个不同输入全部新鲜评分；XCOMET 对本轮与历史译文不同的输入新评分，其余使用同 checkpoint 对完全相同输入的既有分数；覆盖全部 32,384 个系统输出。
XCOMET 共对 2,583 个新输入评分，复用 15,770 个完全相同输入的分数。

## 运行口径

- Q8_0 和 vLLM 共用同一 FLORES-101 devtest、提示词、贪心解码及 512 token 上限。Q8_0 使用 llama.cpp；vLLM 根据上一轮整卡峰值校准 `gpu_memory_utilization`，再按请求区间遥测反馈调整。
- BF16 的低显存运行与原高显存运行逐条译文一致率见表；FP8/NVFP4 也列出与原运行的一致率。所有译文变化都进入本轮质量统计。
- RTX 3090 上 FP8 和 NVFP4 使用 Marlin W8A16/W4A16，而不是原生 FP8/FP4 激活计算。每种版本实际显存峰值在 6.48–6.56 GiB。
- 显存为 `nvidia-smi` 整卡采样，Q8_0 379 个样本、三个 vLLM 各约 100 个样本。吞吐不含模型加载与预热。token/s 使用全量生成 token 数除以推理 wall time。
- XCOMET 对 15,770 个与此前版本完全相同的输入复用了同 checkpoint 分数；对剩余 2,583 个唯一输入新评分。COMET 和 MetricX 对全部 18,353 个唯一输入新鲜评分。

原始输出、全量显存遥测、唯一输入清单与评分映射见本目录的 `q8_0/`、各 vLLM 子目录及 `scoring/`。
