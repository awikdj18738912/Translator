# 六种 Transformers / vLLM 后端实测对照

每种后端覆盖 FLORES-101 devtest 的 8,096 条中文源句到八种目标语言翻译，每语种 1,012 条。BLEU、chrF++、COMET、MetricX、XCOMET 均使用本目录中的新鲜评分结果。三个神经指标先按 `(source, hypothesis, reference, language)` 精确去重，再将分数映射回全部系统输出。
本次对照共映射 48,576 个系统输出，神经模型只需评分 25,896 个不同输入；覆盖检查通过。

运行设置：vLLM FP8 / NVFP4 是 W8A16 / W4A16；Transformers FP8 / NVFP4 是 W8A8 / W4A4，使用 BF16 计算并解压权重后通过 compressed-tensors 软件 QDQ 执行。两种后端的量化路径不同。Transformers 日志还显示 Qwen3.5 fast linear attention 依赖未安装，因而回退至 PyTorch 实现；速度只代表本次环境。速度来自生成阶段记录，指标评分耗时不计入翻译吞吐。

## 指标说明

- spBLEU 与 BLEU-13a：SacreBLEU corpus BLEU，分别使用 FLORES-200 SentencePiece 与 13a tokenizer。BLEU = 100 × BP × exp((1/4)Σₙ₌₁⁴ log pₙ)，其中 pₙ 为截断 n-gram 精确率，BP = min(1, exp(1 − 参考长度/译文长度))。BLEU-13a 仅报告英语、法语、德语、西班牙语、俄语、阿拉伯语六语。
- chrF++：字符 1–6 gram 与词 1–2 gram 的匹配精确率/召回率，使用 Fβ = (1+β²)PR/(β²P+R)，β=2。
- COMET WMT22-DA：结合源文、译文、参考译文预测人工质量分；越高越好。
- MetricX-24 Hybrid XL：reference-based 源文、译文、参考译文错误分；越低越好。
- XCOMET-XL：逐句整体质量分，错误跨度另存；越高越好。
- 这些分数衡量参考译文相似度或模型预测的质量，不是正确率百分比。神经指标按每语种 1,012 个句分求均值，再对八语等权宏平均。
