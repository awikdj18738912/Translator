# 中文→外文翻译评测：全量结果

翻译生成：2026-10-20；补充 BLEU-13a、MetricX-24、XCOMET-XL：2026-10-21。三模型都使用 FLORES-101 devtest 全量，每个目标语 1,012 条，八种目标语共 8,096 条/模型。翻译为 BF16、贪心解码、batch=128，GPU1（RTX 3090 24GB）。

公开基准不等同于业务或 ASR 语料；分数是参考译文一致性/模型评分，不是正确率百分比。

## 指标怎么算、用来做什么

| 指标 | 计算方式 | 用途与方向 |
|---|---|---|
| BLEU / spBLEU | 语料级 1–4 gram 修正精度并乘简短惩罚；BLEU-13a 用 13a 分词，spBLEU 用 FLORES-200 SentencePiece。 | 衡量译文与参考的词片段重合；越高越好。两种分词的分数不能直接比较。 |
| chrF++ | 汇总字符 1–6 gram 和词 1–2 gram 匹配，计算 β=2 的 F 分数。 | 对词形变化和书写差异更宽容；越高越好。 |
| COMET WMT22-DA | 神经评分器联合输入中文原文、模型译文和参考译文，预测与人工 Direct Assessment 相关的质量分。 | 补充词面指标的语义质量信号；越高越好，不是正确率百分比。 |
| MetricX-24 Hybrid XL | mT5 回归评分器联合读入 source、candidate、reference，预测 DA/MQM 风格错误分，截在 0–25。 | 估计译文错误程度；越低越好。模型以 WMT 数据训练，本次中文→多语结果用于相对比较。 |
| XCOMET-XL | 神经评分器输入原文、译文和参考，输出质量分及 minor / major / critical 错误片段。 | 提供语义质量信号和错误定位；分数越高越好。错误片段仍需人工复核。 |
| TTFT / 批延迟 / 摊销延迟 | 分别是批首 token 时间、整批完成时间、整批时间÷批量；报告 p50/p95。 | 看响应等待和尾部延迟；越低越好。batch=128 的摊销值不代表单句交互延迟。 |
| 句/秒、字符/秒、token/秒 | 用全量输出条数、字符数或 token 数÷全量累计批延迟；decode token/s 只计首 token 后的 token÷首 token 后的解码耗时。 | 衡量生成吞吐；不同 tokenizer 下 token/s 不宜直接排名。 |

- FLORES-101 devtest：每目标语 1,012 条；全量输出和评分见本目录下的 `index/`、`hy/`、`lmt/`、`comet_wmt22/`、`metricx/`、`xcomet/`。逐语种机器可读数据见 [full_language_results.json](full_language_results.json)；MetricX 与 XCOMET 评分入口分别见 [score_metricx24.py](metricx/score_metricx24.py)、[score_xcomet_full.py](metricx/score_xcomet_full.py)。
- BLEU-13a 只报英语、法语、德语、西班牙语、俄语、阿拉伯语；SacreBLEU 说明日语和韩语需 ja-mecab / ko-mecab 分词，本环境未安装相应依赖。日、韩仍有 FLORES-200 spBLEU。
- COMET 全量分语种值和 bootstrap 明细见 [COMET 报告](comet_wmt22/report.md)。96 条人工盲评样本表已准备，但尚无人评分。
- XCOMET-XL 使用已授权的 Hugging Face 账户完成全量评分；模型许可为 CC-BY-NC-SA-4.0，限非商业评测等许可范围内使用，详见 [模型页](https://huggingface.co/Unbabel/XCOMET-XL)。
- FLORES 是公开书面语测试集，不能代表真实 ASR 业务分布。
