# LMT-60-0.6B 与现有多语模型对比

日期：2026-10-17。基于本地实际推理产物，指标从逐句原始输出独立复算。

## 测试口径

- FLORES-101 devtest，英语、法语、德语、西班牙语、俄语、日语、韩语、阿拉伯语到简体中文；每语种1012句，共8096句。四模型使用同一数据、同一参考译文和固定种子选取的100句/语种流式子集。
- BLEU 使用 SacreBLEU 中文 zh tokenizer，chrF++ 使用 word_order=2；输出和参考均经 OpenCC 简体转换。每个语种分开计算，宏平均是8个语种分数的算术平均，不是合并语料后的分数。分数不是百分比准确率。
- FLORES 是公开书面文本基准，可能进入模型训练、开发或选择流程；不能代表未见业务文本。这里没有音频、ASR、术语库、业务后处理或真实语音到达时间。
- 两种增量更新均以人工切分的源文本前缀驱动，是文本回放，不是模型原生源流式能力。延迟是模型更新计算耗时，不含采音、ASR、排队或端到端字幕时间。NE、非EOS更新和空白更新按两个模式分别统计。
- 四模型 GPU 主评测均为 int8_float16：LMT 使用 CTranslate2 4.8.3 Generator，旧三模型使用 4.6.3 Translator；计算精度相同。LMT 全量 batch=1，旧模型为 batch=4；测试时间和共享 GPU 负载也不同，速度数据不能直接用于严格排名或速度倍数结论。另有原始权重 CPU FP32 的25个业务样例对照，单独报告，不参与 GPU 时延统计。

## LMT运行配置与状态

模型：NiuTrans/LMT-60-0.6B（翻译微调版，不是 Base）；许可：Apache-2.0。revision：`dd189845cdc73346cef33c7a94f4b8bd8efdd4eb`；runtime：`CTranslate2 4.8.3 Generator`；compute type：`int8_float16`；beam：3；实际 offline batch：1；stream batch：1。GPU indices：[0, 1]（来自合并 metadata）。报告读取 metadata 实际值，不预设 batch 大小。旧模型运行时及精度配置见各自 metadata。 实际唯一参数量：596,049,920；checkpoint tensor统计中包含重复的共享embedding/lm_head，已核对二者权重相同。参数和术语编码检查见 tokenizer_and_parameter_audit.json。

## 业务语义核查记录

以下是根据本次构造样例源文和参考译文进行的定向核查，不是独立业务人审，也不估计生产正确率。主评测采用作者默认翻译提示词，没有加入外贸场景说明、术语表或之前的对话。

- `en_order`：GPU混合精度输出保留了500、SUS304、阀门、每个12.50美元及11月15日交货信息，较此前金额或物品名错误的基线更好。
- `fr_order`：GPU输出“500个SUS304泵”，原始权重CPU FP32对照也输出“泵”。本例参考物品是阀门，错误并不只出现在量化版本。
- `ar_correction`：本例预期表达“不要发500件，改成300件，收到预付款后才发货”。GPU和CPU FP32都选择了“充电”义；阿拉伯语词形有多义性，在该外贸业务意图下词义选择不符，不能将其扩大为所有使用场景下的词义错误。
- `en_correction`：GPU输出“付款后才发货”，原始CPU对照输出“收到押金后发货”。GPU版本保留了付款先于发货的条件，但没有保留定金这一具体付款类型。两种引擎及精度的输出存在差异，不能将全部差异归因为量化。
- `en_asr_revision`：普通重译与锁定前缀两种GPU终态都把“500改成300”的数量修正保留下来，但添加了原文未明确要求的“安装”动作；原始CPU整句对照使用“交付”。这也是事实保真方面的待解决问题。

八条报价的金额与术语命中是同一模板不同语言的字段检查。例如保留“12.50美元”并不能证明“单件价格”关系准确，也不能证明没有遗漏交期或改变付款条件。仍应保留源文与中文共同核对。
